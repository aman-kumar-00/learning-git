# learning-git
learning git command by doing it 

git init → initialize repo

git add . → add all at once files

git add filename.txt  ->  for single file or manually add multiple file 

git commit -m "msg" → save changes

git push → upload to GitHub

git status - show the untracked file 

.gitkeep - it will keep the folder and show it with git status command 
.gitignore - it will ignore the file or folder
